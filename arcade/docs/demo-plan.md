# Meowcana — Demo Build Plan

Game title: **Meowcana**, tagline **Swap. Chain. Pounce.** (renamed from the GDD's working title
"Nine Lives Arcana: The Cats and the Rat King"; world and character names are unchanged).

Source design: the game design document kept outside the repo (the "GDD"; design notes are not in
English, all in-game text is American English). This file is the shared contract for everyone building the demo.
**Every file in this repo and every string the player can see is American English.**

## 1. Demo scope

Flow:

```
Title ──► "Learn to Play" (tutorial) ──► Chapter 1: The Dusty Attic ──► Boss: Chubbs ──► Demo End
      └─► "Skip Tutorial" ──► Fate's Draft (same 3 picks) ──┘
Defeat anywhere in Chapter 1 ──► Nine Bells −1 ──► Moonnap Parlor ──► new run (draft again, no tutorial)
```

- **Tutorial ("Prologue: The Reading Table")**: Zero teaches a child-level lesson set through 3 tiny
  scripted battles. Each battle ends with a **Pick 1 of 3**. Lessons, in order:
  1. *Cards go left to right.* The Paw plays your cards one by one, then the rat plays one. A = Fight,
     A in battle = speed, B = skip. C = "what does this do?" (Info). Practice Mouse, HP 8.
  2. *Neighbors matter.* Elemental Dignity: a planted Hiss (Fire next to Water). Zero asks you to pick up
     the Water card and move it; numbers change live. New card from lesson 1 sits in the Box: move it in.
     Dust Mouse, HP 14.
  3. *Count up.* Number Path (Step, Catwalk) and Reversed cards / Domino's Two-Tone. Arrange 3-4-5.
     Coin Mouse, HP 18, uses Cracked Coin (Curl) so you see a shield.
- **Skip path ("Fate's Draft")**: three Pick 1 of 3 screens drawn from the same seeded pools
  (`draft_options(run, i)`), plus a one-screen "How to Play" card the player can reopen with C.
  Both paths enter Chapter 1 with the same deck strength.
- **Chapter 1**: Night Path of **6 steps + Boss** (GDD says 8; shortened for demo pacing). Nodes: Rat Fight,
  Elite (Sir Flea or Dog-Ear), Spots' Stall, Encounter (6), Cat Bed, Cardboard Box. Level ups, Treats,
  Charms, Stars, Merge. First-time contextual tips from Zero (first Stall, first Major, first Elite,
  first Curse, before Boss).
- **Boss**: Chubbs, the Pantry King (Bottomless Belly, Still Hungry). Win → story → **Demo End** screen:
  "Night One is over. The rest of the night is still being written." Hidden chapters stay hidden.
- **Meta**: Moonnap Parlor (Start Night, Nine Bells), save/continue at node boundaries, records
  (wins, best hit, fastest). Almanac is a stretch goal, off by default.
- **Cut from demo**: Almanac grid, Settings beyond "Battle speed" and "Erase save", Zero's Pick.

## 2. Hardware budget (measured; design to it)

- One `arcade_draw_ops` RPC per ≤200-byte chunk, **≈17 ms each**. Bytes are expensive: a frame that
  sends 1 KB costs 5 RPCs ≈ 85 ms.
- Per draw op ≈1.5 ms setup. Fills where color hi byte == lo byte ≈770 kpx/s, other fills and bitmaps
  ≈180 kpx/s. Full-screen bitmap ≈0.85 s. These may improve (see §4 Platform) — the simulator's cost
  model (`python/costmodel.py`) is the source of truth.
- Frame budget: menus/idle ≤ 45 ms estimated device time per frame; battle animation ≤ 70 ms.
  Full redraws only on scene change (behind a transition). Everything else is dirty-rect.
- Flash for assets ≈600 KB. No alpha; transparency = paint with a known flat background color.
- Inputs: joystick + A (Do) / B (Back) / C (Info). No audio: all feedback is visual.

## 4. Platform contract (engine + sketch + simulator)

`engine.Screen` (Python) keeps `clear, fill_rect, rect, fill_circle, circle, line, fill_triangle,
sprite, asset, hide, take, discard` and gains:

- `text(x, y, msg, color, bg=None, font=BODY, scale=1)` — baked bitmap fonts from
  `design/styles/moonlit-grimoire/fonts/`: `BODY` = VT323 16 px, `TITLE` = Jacquard 24 (mixed case only),
  `NUM` = Jersey 10 at 20 px (digits and `+-x%!/`), `TINY` = Silkscreen 8. `bg` given = opaque cell
  (fast); `bg=None` = transparent (slow, small text only). Replaces the built-in GFX font.
- `measure(msg, font=BODY, scale=1) -> (w, h)` and `text_center(...)`, `text_right(...)`.
- `asset(..., flip=False, flip_y=False, tint=None)` — `tint` paints every opaque pixel one color
  (white hit-flash, red hurt, silhouette).
- `asset_region(asset, frame, x, y, sx, sy, w, h)` — draw a sub-rectangle of an asset (restore a
  background bitmap under something that moved).
- Any composite op UIKit asks for (e.g. a whole card with rim + stars + charm in one op) if it saves bytes.
- `tools/sim.py`: runs the real game on PC. Decodes the exact op bytes into a 480×320 image using the
  packed asset/font data. Interactive window (arrows = stick, Z = A, X = B, C = C) and headless mode:
  `python tools/sim.py --keys "1.0s,A,R,R,A,2.0s" --shots build/shots/ --every 0.5` that writes PNGs and a
  cost log (estimated device ms per frame: RPC chunks, ops, pixels). Agents verify visuals with it.
- Stretch (high value): faster TFT writes (direct GPIO for the 8-bit bus) — measured on the board.
  **Status: implemented, unmeasured.** `ARCADE_FAST_BUS` in `sketch/sketch.ino` (default 0) drives the bus with
  direct STM32U585 GPIO writes (README "Faster TFT bus"); `python scripts/deploy.py --bench --fast-bus` sweeps
  library vs three direct modes and prints kpx/s so `python/costmodel.py` can be updated. Until then the §2
  numbers stay as measured with the library bus.

As built (see README sections 7-8): `text` y is the top of the cell (baseline `y + ascent*scale`,
`font_metrics(font) -> (height, ascent)`); the opaque cell is exactly `measure()` wide. Extra ops beyond the
list above: `blit` (untracked asset draw, `bg=None` = transparent runs), `dim=True`, `dotted_rect`,
`card(face, frame, x, y, rim, bg, field, stars, star_asset, gem, gem_asset, dim, tint, scale)` (a whole card in
one 18-byte op), `stats()` (ops/bytes/chunks/est. ms) and `Runner` reading `game.busy`. Only ASCII 32..126 is
baked; VT323 BODY has a 6 px advance. Flash budget is enforced by `tools/pack_assets.py` (560 KB).

## 5. Rules contract (`python/nla/rules/`, pure Python, no engine imports)

Implements GDD §7–§14 for the demo (40 Minor, 8 Major, 9 Charms, Readings incl. Major Readings,
5 Statuses, Burnout, all Chapter 1 rats, Chubbs). Names must match below; extra fields are fine.

```python
# cards.py
FIRE, AIR, WATER, EARTH = 0, 1, 2, 3
@dataclass(frozen=True)
class CardDef: id: int; name: str; element: int; number: int; is_major: bool
@dataclass
class Card:
    def_id: int; reversed: bool = False; star: int = 0; charm: int = 0   # star 0..2 = ★1..★3
    uid: int = 0                                                       # stable identity for UI
def card_title(card) -> str            # "Fire Claw", "The Sun"
def card_subtitle(card) -> str         # "Wands 4 · ★1 · Upright"
def card_text(card) -> list[str]       # rules text, ≤3 lines × 56 chars
CHARMS: dict[int, CharmDef]            # name, rarity, text

# readings.py
@dataclass
class SlotInfo: power: int; base: int; parts: list[tuple[str, str]]   # ("Nuzzle", "+2"), ("Two-Tone", "+25%")
@dataclass
class Link: a: int; b: int; kind: str   # "nuzzle" | "tail_tap" | "hiss" | "step" | "mirror" | "litter" | "journey"
@dataclass
class SpreadReport:
    slots: list[SlotInfo | None]; links: list[Link]
    readings: list[str]                 # "Nuzzle x2", "Catwalk", "Lion Sun"
    per_round: dict[str, int]           # {"dmg":, "singe":, "heal":, "curl":}
def analyze(spread: list[Card | None], run, enemy=None) -> SpreadReport

# battle.py — whole battle computed at once; UI only plays it back
@dataclass
class Event:
    kind: str        # battle_start round_start paw play reading hit damage heal curl status flip
                     # eat phase add_card leap_block crit burnout ko end line
    side: int        # actor: 0 Domino, 1 enemy
    slot: int = -1   # actor's slot (or target slot for eat/flip)
    value: int = 0
    label: str = ""  # "Fire Claw", "Nuzzle", "Singe", boss line text for kind == "line"
    tier: int = 0    # chain length tier 0..4 for "reading"/"play"
    crit: bool = False
    hp: tuple[int, int] = (0, 0)              # both sides' HP after the event
    status: tuple[dict, dict] = ({}, {})      # both sides' statuses after the event
@dataclass
class BattleResult: events: list[Event]; won: bool; hp_left: int; treats: int; xp: int; best_hit: int
def simulate(run, enemy, seed: int) -> BattleResult

# enemies.py
@dataclass
class EnemyDef: key: str; name: str; hp: int; spread: list[Scrap | Card]; tier: str; intro: str
ENEMIES: dict[str, EnemyDef]   # practice_mouse dust_mouse coin_mouse gray_rat pickpocket paper_chewer
                               # stinker rat_sergeant sir_flea dog_ear chubbs

# run.py
@dataclass
class RunState: seed; hp; max_hp; treats; spread: list[Card|None]; spread_size; box: list[Card|None];
                box_size; level; xp; step; path: list[Node]; flags: dict; bells: int; ...
def new_run(seed, tutorial: bool) -> RunState
def draft_options(run, pick: int) -> list[Card]           # same pools for tutorial rewards and draft
def path_options(run) -> list[Node]                      # 2 choices; Node(kind, key, label)
def battle_rewards(run, enemy, result) -> Rewards        # treats, xp, 3 card options (+ Chewed Major)
def take_card(run, card) -> str                          # "spread" | "box" | "duplicate" | "box_full"
def merge(run, card, target_uid) ; level_up_options(run) ; apply_level_up(run, key)
def stall_stock(run) ; buy(run, item) ; sell(run, uid) ; reroll(run)
def cat_bed(run, choice, uid=None) ; encounter(run) -> EncounterDef ; resolve_encounter(run, choice, uid=None)
# save.py
def save_run(run, path) ; load_run(path) ; load_profile(path) ; save_profile(profile, path)  # atomic
```

`tools/balance.py`: headless Monte Carlo of whole runs with a simple bot (greedy arrange) to tune numbers
to GDD §14 (battle 20–40 s at 1×; Chubbs win rate for a decent player ≈ 60–75 %).

## 6. UI contract

- **UIKit** (`nla/ui/`): `theme.py` (Moonlit palette from `design/styles/moonlit-grimoire/pal.py`,
  font roles, layout grid from its `notes.md`), `input.py` (GDD §6.1: main axis > 50 %, diagonals
  ignored, repeat after 300 ms every 120 ms; A/B/C press edges), `app.py` (scene stack, `push/pop/switch`,
  transitions: card-flip wipe), `widgets.py` (card face/back/small card, slot outline, cursor brackets + paw,
  panel with flourish corners, divider, footer button hints, HP bar, status chips, popup/toast, dialogue box
  with portrait, confirm box, info overlay), `fx.py` (shake, flash, floating text, particles, hit-stop).
- **Scene interface**: `class Scene: enter(app); update(ctl, dt); draw(scr, full)`; scenes finish by calling
  a `done(result)` callback passed to their constructor. Scenes never import each other; `flow.py` wires them.
- **Services** (Flow implements `nla/flow.py:Services`; scene dev harnesses use a stub): every scene is
  constructed as `XScene(services, ..., done)`. `services` provides: `app` (UIKit App), `run` (RunState),
  `profile`, `report(action_key)` (tutorial progress, keys from `docs/story-and-tutorial.md`; no-op
  outside the tutorial), `tutor` (None outside the tutorial; otherwise exposes `step` with
  `highlight/allow`), `pick_card(purpose, selectable, on_pick, button="Cancel")` (pushes the Card Picker;
  `on_pick(uid | None)`), `menu()` (pushes the Menu), `tip(key, then=None)` (plays `story.TIPS[key]` once if
  the Rules flag is armed), `say(lines, then=None)` (dialogue overlay), `card_info(card)`, `save()`.
  Every scene also implements `region(key) -> (x, y, w, h) | None` for tutorial highlight keys it shows.
- Constructors: `SpreadScene(services, enemy, done, lesson=None)` → `done("fight")`;
  `BattleScene(services, enemy, result, done)` → `done({"won", "skipped"})` (includes the Result panel);
  `RewardScene(services, options, done, title="Pick 1 of 3", skip_treats=3)` → handles take/merge/box-full
  via Rules, `done(card | None)`; `PickerScene(services, purpose, selectable, done, button="Cancel")` →
  `done(uid | None)`; `PathScene(services, done)` → `done(node)`; `StallScene`, `CatBedScene`,
  `EncounterScene`, `BoxScene`, `LevelUpScene(services, done)` → `done(None)`; `MenuScene(services, done)` →
  `done("resume" | "how_to_play" | "save_quit" | "abandon")`.
- **Scene agents**: Battle (`scenes/battle.py`: playback of `BattleResult` with animations, attack VFX,
  hit reactions, chain popups, crits, boss phase); Spread (`scenes/spread.py`, `picker.py`, `reward.py`,
  `cardinfo.py`); Path (`scenes/path.py`, `stall.py`, `catbed.py`, `encounter.py`, `levelup.py`, `menu.py`);
  Flow (`scenes/title.py`, `parlor.py`, `story.py` cutscenes, `tutorial.py`, `draft.py`, `ending.py`,
  `nla/flow.py`).
- Key semantics are global (GDD §6.2): A = Do (only key that commits), B = Back (never commits an
  irreversible action; jumps the cursor to the exit button instead), C = Info (never changes state).
  The footer always shows the current A/B/C meaning.

## 7. Art contract (`assets/`, `tools/art/`)

- Style: **Moonlit Grimoire** exactly (`design/styles/moonlit-grimoire/`: notes.md, render.py, ui.py,
  icons.py, pal.py). Every pixel RGB565-exact, palette from `pal.py`.
- Domino = merge candidate **B** `design/styles/moonlit-grimoire/raw/domino_merge_b.png` (Apprentice
  Seer robe/hat + tuxedo fur, brighter amber eyes, gold held card as shown on `domino-merge.png`),
  processed like that sheet (`render.sprite(..., cool=True)`), faces **right**. All rats and Chubbs face
  **left**.
- Character design rule: every character is **lightly anthropomorphic like Domino** — stands upright,
  wears a costume and holds a prop that tells their role (Pickpocket: thief hood + sack; Paper Chewer:
  torn-page apron + quill; Stinker: grimy overalls + plunger; Rat Sergeant: tin-can helmet + toothpick
  spear; Sir Flea: tiny knight armor riding a cockroach; Dog-Ear: scholar robe + spectacles + book;
  Spots: merchant vest + monocle; Zero: ghostly kitten in a too-big Fool's scarf with a bindle;
  Granny Oriel: sleeping old woman in a shawl). Never a plain animal on all fours. The existing Chubbs
  (`raw/chubbs.png`) is the reference for the rats' look and stays. Tutorial mice: small apprentice
  rats in cardboard armor.
- Animations: idle loop + attack for every fighter (PixelLab `animate-with-text-v3` from the base sprite),
  Domino also cast/victory if budget allows. Hurt = engine `tint` flash + shake (code, free). Defeat =
  code (sink + fade to silhouette). Hit VFX (slashes, sparks, element particles) are small code-drawn or
  baked sprites.
- Baked: sprites, card faces 48×64 and 40×54 per card def × orientation, scrap cards, card back, icons,
  battle backdrop (Dusty Attic), title/parlor art, path map art, dialogue portraits. Code-drawn at runtime:
  panels, rules, text, bars, cursors, rims, stars, charm gems if cheaper.
- `docs/assets.md` lists every asset name, size, frames, fps, meaning. Placeholders first (so UI agents can
  build), final art after.
- **PixelLab budget**: $2.00 credits + ~11 trial generations left. Trial first. Hard cap **$1.50** of spend.
  Dry-run price checks before every batch. Never write the API key to a file.
